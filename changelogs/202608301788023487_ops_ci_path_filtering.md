# [ops] ci: Add Path Filtering to Isolate Backend and Frontend CI/CD Triggers

**Date:** 2026-08-30  
**Timestamp:** 1788023487  
**Type:** `[ops]` CI/CD  
**Service:** `.github/workflows/ci.yml`

---

## Summary

Added `dorny/paths-filter@v3` to `.github/workflows/ci.yml`. CI jobs are now isolated by workspace path:
- Changes affecting `apps/api/**` only trigger the `security` (SAST) and `api` (Go build/test) jobs.
- Changes affecting `apps/web/**` only trigger the `web` (React/Vite build/test) job.
- Changes to shared files (e.g. `Makefile`, workflows) trigger both pipelines.
- Deployments in `cd.yml` remain strictly isolated by git tag prefixes (`production-api-core-v*` vs `production-web-v*`).
