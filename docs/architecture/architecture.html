Loops 1–3 chain autonomously in a single request. A recommendation is advisory: nothing settles or closes until POST /v1/claim/{id}/approval records a human decision.

Does the recommendation follow the record, or a script?

Same claim, same policy, one field changed. Each recommendation names the real policy number, ceiling, deductible and computed settlement. Every RECOMMENDATION_GENERATED event records the engine that answered — gemini-3.5-flash via vertex-ai — so model output is distinguishable from the deterministic fallback used when no credential is configured.
